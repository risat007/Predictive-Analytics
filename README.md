## Abstract

This report analyzes the public GitHub project Predictive-Analytics. The project demonstrates predictive analytics through three complementary tasks: stock-price forecasting with a Long Short-Term Memory (LSTM) neural network, daily sales forecasting with Holt-Winters exponential smoothing, and waiter-tip prediction with regression models. The repository contains an executed Jupyter Notebook and an Excel workbook named Analytics_Dataset.xlsx. The workbook is read through three sheets: Stock_Prices, Sales_Data, and Waiter_Tips.

The notebook reports a time-based LSTM experiment using a 20-observation sliding window. The data is scaled with MinMaxScaler, split chronologically into 784 training sequences and 196 later test sequences, and modeled with an LSTM layer of 32 units followed by dense layers. The reported held-out RMSE is $6.67 for the selected stock series. For the North store sales series, the notebook uses seven-day seasonal decomposition and an additive Holt-Winters model; the reported RMSE on the final 60 days is 28.2 units/day. For waiter-tip prediction, the features include bill amount, customer characteristics, day, meal period, and party size. Ridge regression and ordinary linear regression reach approximately R² = 0.514, improving on the bill-only baseline of 0.472, while Random Forest reaches 0.410 on the same test split.

The project is valuable as a compact demonstration of several predictive techniques. Nevertheless, the results should be interpreted as notebook-specific experiments rather than universal performance claims. The notebook includes an interrupted TensorFlow installation cell, a Windows GPU-support warning, a variable-name inconsistency in the stock plotting code, and single holdout evaluations without confidence intervals or rolling-origin validation. These issues do not invalidate the educational workflow, but they identify important improvements for a production-ready predictive analytics system.

*Keywords:* predictive analytics, time-series forecasting, LSTM, Holt-Winters, regression, Ridge regression, Random Forest, stock prices, sales forecasting.
